# OppTrack Documentation

OppTrack is a student opportunity tracker. It helps students find openings, save the ones that matter, and keep track of applications without losing everything in a spreadsheet.

This folder is the technical documentation for the current project.

## Docs

- [Architecture](./architecture.md) — how the React frontend, Express backend, and PostgreSQL database fit together
- [Database](./database.md) — schema, relationships, and how users, opportunities, saved items, applications, and sessions are stored
- [Authentication](./authentication.md) — registration, password hashing, login, sessions, HTTP-only cookies, and auth middleware
- [API Reference](./api.md) — REST routes on the Express backend
- [Deployment](./deployment.md) — local vs production setup, and how Netlify, Render, and Neon are wired
- [Security](./security.md) — what’s in place today and what still needs hardening
- [Development](./development.md) — project layout, env setup, and the commands you’ll actually use
